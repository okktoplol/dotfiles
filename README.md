# dotfiles

### software used
- shell: [zsh](https://www.zsh.org/) + [oh my zsh](https://ohmyz.sh/)
- coreutil alternatives: [eza](https://github.com/eza-community/eza) (instead of zsh) + [bat](https://github.com/sharkdp/bat) (cat alternative)
- terminal emulator: [kitty](https://github.com/kovidgoyal/kitty)
- editor: [doom emacs](https://github.com/doomemacs/core)
- web browser: [firefox](https://www.firefox.com/en-US/)
- search engine: [4get](https://git.lolcat.ca/lolcat/4get)
